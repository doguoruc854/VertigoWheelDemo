# Vertigo Wheel Demo

A Wheel of Fortune style mobile game built with Unity 2021.3 LTS, targeting Android.

Wheel slice contents (rewards, bomb slices, and selection weights) are ScriptableObject assets. Designers can change a wheel’s layout in the Inspector without touching code.

## Requirements

- Unity 2021.3 LTS
- Android Build Support (SDK, NDK, OpenJDK)
